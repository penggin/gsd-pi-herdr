# M1.13 — Real Herdr v0.8.2 root integration smoke

Date: 2026-08-30

## Purpose

Validate the M1 root integration against a real Herdr v0.8.2 server and a real Herdr-managed pane rather than only fake sockets/unit tests.

This smoke covers the M1 contract: environment discovery, socket request compatibility, root lifecycle reporting, session replacement/reload, diagnostics, and shutdown authority release. macOS-specific pane focus/process-group/reconnect behavior remains part of later worker-backend and durability E2E work.

## Compiled client/root reporter smoke

The compiled downstream `HerdrClient` and `HerdrRootReporter` were connected directly to the real API socket for a Herdr-managed pane. Stable observations used a 300 ms bound because extension lifecycle handlers intentionally issue bounded fire-and-forget reports rather than blocking the TUI on the external socket.

Observed `pane.get` results:

| Step | Effective Herdr state |
|---|---|
| `sessionStart` | `agent=gsd`, `idle` |
| `agentStart` | `working` |
| normal `agentEnd` | `idle` |
| terminal error, `willRetry=false` | `blocked` |
| error, `willRetry=true` | `working` |
| replacement `agentStart` | `working` |
| `shutdown` / `release_agent` | `unknown`, no owning agent |

A separate direct-client state smoke also proved v0.8.2 accepts the exact emitted request fields for custom agent labels and the semantic states `working`, `blocked`, and `idle` before release.

## Actual bundled GSD TUI smoke

A fresh Herdr workspace produced pane `w2:p1`, then the actual downstream build was launched in the pane:

```text
node /src/penglab/dist/loader.js
```

Herdr immediately observed:

```text
agent=gsd
agent_status=idle
```

No test-only root reporter invocation was used for this observation; it came from the bundled `herdr` extension loaded by GSD.

### Session/runtime lifecycle

- `/new`: GSD confirmed a new session; Herdr still reported `agent=gsd`, `idle`; `/herdr-status` remained active.
- `/reload`: GSD reloaded extensions; Herdr still reported `agent=gsd`, `idle`; the reloaded `/herdr-status` remained active. This validates the unique-runtime-source / monotonic-in-runtime sequence strategy against the real v0.8.2 sequence watermark behavior.
- `/quit`: GSD exited back to the pane shell while the pane remained alive. Herdr then reported `agent_status=unknown`, proving `session_shutdown` released lifecycle authority.

## Configuration hygiene

The live bundled-TUI test needed `herdr.enabled: true`. Before the test, the DevSpace global `~/.gsd/PREFERENCES.md` path was checked and confirmed absent. A minimal temporary file was created, then removed immediately after `/quit`:

```yaml
---
herdr:
  enabled: true
  required: true
---
```

The downstream repository was not modified for this runtime-only configuration.

M1 can close and M2 may begin with local `runSingleAgent()` semantic characterization. Later M4–M6 work still owns macOS-specific focus preservation, foreground process-group cancellation, pane closure, detach/reattach, restart, and worker recovery E2E.
